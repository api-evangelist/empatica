# Empatica

This repository has been taken down at the request of Empatica.

On 2026-10-19, Empatica asked API Evangelist to remove this profile. The request was honored the same day: every file and derived artifact was removed, and the repository was recreated so none of that material remains in its history.

What remains on apis.io is a minimal record: the company name, a short description, and a link to its own website, https://www.empatica.com/. Empatica is unrated and is on the API Evangelist delisting registry, so no pipeline will re-profile it or contact its hosts.

For removal requests or questions, contact info@apievangelist.com.
